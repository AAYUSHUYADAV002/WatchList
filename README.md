# WatchListify – Movie Recommendation System

## 📌 Overview
WatchListify is a web-based movie recommendation system that allows users to discover, manage, and track their favorite movies and shows. It integrates external APIs to provide real-time data and personalized suggestions.

## 🚀 Features
- User-based movie recommendations
- Create and manage personal watchlists
- Real-time updates for new episodes and ratings
- Search movies by genre, actors, and directors
- Responsive and user-friendly interface

## 🛠 Tech Stack
- Java
- Spring Boot
- Hibernate
- MySQL
- Thymeleaf
- REST API (TMDB API)

## ⚙️ How It Works
- Fetches movie data using TMDB API
- Stores user preferences in MySQL database
- Uses Spring Boot for backend logic and REST APIs
- Frontend rendered using Thymeleaf templates

## ▶️ How to Run
1. Clone the repository  
2. Configure MySQL database  
3. Add API key for TMDB  
4. Run the Spring Boot application  
5. Access via browser
